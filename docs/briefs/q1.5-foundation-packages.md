# Q1.5 foundation packages

Two minimal draft API v1 fixtures live here: SubRip import/export and a synthetic audit
policy. Their manifests declare only the host access used by the implementation. The audit
policy reads `policy.json` through `host.data.read`; SubRip needs no host capability. These
packages are local spike inputs, not signed releases or compliance rules.

The app repository's `docs/briefs/08-q1.5-quickjs.md` owns acceptance and measurement.
